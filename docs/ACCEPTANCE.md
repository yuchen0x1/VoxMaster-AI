## 整曲验证 · PASS

用户提供的《private-reference-01.mp3》为 44.1 kHz 双声道录音。测得时长 174.939 秒。输出 WAV 保持 7,714,816 帧，文件为 46,289,034 字节。导出前后原文件哈希相同。首次运行含输入分析、渲染、复测和再次解码总共用时 11.84 秒。录音与导出成品只在本机验收目录中使用。

| 指标 | 输入 MP3 解码 | 输出 WAV 重新解码 |
|---|---:|---:|
| 应用综合响度，LUFS | −3.289 | −15.000 |
| FFmpeg ebur128 综合响度，LUFS | −3.294 | −15.005 |
| 应用四倍过采样真峰值，dBTP | +5.843 | −5.846 |
| FFmpeg ebur128 真峰值，dBTP | +5.783 | −5.849 |
| RMS，dBFS | −6.984 | −19.069 |
| 采样峰值，dBFS | +4.556 | −6.283 |
| 应用记录的近满量程/越界声道采样数 | 175,086 | 0 |

FFmpeg 原生浮点帧的绝对峰值为 1.689652。对原 MP3 直接做浮点解码，即可复现正值 dBFS。它表明固定满量程播放有过载风险，单靠该数值无法追溯录制时是否曾经硬削波。独立电平核对通过 PyAV 把解码帧送入 FFmpeg C 语言 ebur128 滤镜，未调用应用的响度和真峰值函数。原始音乐和导出文件分别扫描。两种过采样实现对输入真峰值的差值约 0.06 dB。

## 扩展音频体检与参考比较 · PASS

执行 `.\.venv\Scripts\python.exe -m pytest tests\test_acoustics.py -q` 通过 5 个专项用例。独立构造的信号覆盖跨处理块满幅平顶、单个越界浮点采样、220 Hz 稳定音、120 BPM 的规则律动、150 ms 的衰减重复，以及衰减斜率为 −48 dB/s 的宽带尾音。另用高于 A4 25 音分的稳定正弦信号校验音级偏差，实测 24.9 音分。安静素材返回未知延迟和衰减。

- 真人整曲原文件测得 240,767 个声道采样 ≥ −0.1 dBFS，其中 174,957 个超过 0 dBFS，连续满幅平顶候选为 0。后者只计同一声道连续至少三个近似等值的满幅采样；其证据范围限于当前解码波形。强起音候选 77 处，其来源可能是人声或鼓点。
- 该整曲的 96 个等距频谱取样窗给出频谱重心 1,225 Hz、85% 能量频率 2,369 Hz。基频估计帧的第 10–90 百分位为 89.3–494.4 Hz，检出两段稳定音高，最长 0.42 秒。该结果同时可能包含人声和乐器。整曲额外特征提取用时约 0.10 秒，不含已有的完整音高分析。
- 真人普通话样本检出 27 个强起音候选，基频估计的第 10–90 百分位为 116.5–159.8 Hz，未发现连续稳定 240 ms 的音高。与该样本相比，整曲的 1.8–4.8 kHz 相对频段能量高 7.0 dB，侧声道能量占比高 10.6 个百分点。采样率和内容差异都会影响频段比较。
- 两个文件均未获得满足阈值的稳定尾衰减和重复间隔。测量只有在至少一段下降曲线具有足够的跨度及线性拟合度时才给出估计，回声间隔候选要求至少三处相似衰减副本。源发声自然下降、乐器重击和节奏重复也可能产生相同特征。人声/伴奏比例需结合分离轨道另行测量。
