# 0.1.1 真实录音与音频质量验收

2026-11-18 在 Windows 11 Pro x64、AMD Ryzen 9 8945HX、44.1 kHz 双声道浮点工作总线上，分别运行 0.1.0 和 0.1.1。**23 份输入均完成两次版本独立的整段分析、参数生成、DSP 渲染和成品复测**。从中提取 28 段同源区间，获得 84 个等响文件。用户另对《习武弃文》57–69 秒完成一次两版盲听，选择了 0.1.1。设备及选择原因未提供。[收取的听审记录](LISTENING-011.md)

## 素材与版本

- 五首用户指定的本地中文喊麦混音，音频和输出片段保存在本机 build/acceptance-011。每首分别选取前半段 PCM 平均能量最强的 12 秒、时长约 71% 处的 12 秒。选择发生在版本比较之前，能量筛选会偏向密集编曲。
- 七份 VocalSet 专业歌手实录，按原始数据集的性别、演唱练习和技巧分组，包括气声、强声、vocal fry、快速音阶和弱声长音。使用固定 ZIP 成员，读取时检验 ZIP 大小、成员 CRC 及最终文件 SHA-256。数据集以 CC BY 4.0 发布，作品署名见 [VocalSet](https://zenodo.org/records/1203819) 和 [逐文件来源清单](../tests/mc_corpus/sources.json)。
- 八份 Freesound CC0 实录的官方 HQ MP3 预览，含两个独立英语说唱人声、低声吟唱、带效果的假声、领夹麦说话、远距人群、实体鼓和齿音低语。原始器材与音频后处理以作品页说明为准。[两首无伴奏 Rap](https://freesound.org/people/Plaedo/sounds/207620/) · [84 BPM 无伴奏 Rap](https://freesound.org/people/blainksaint/sounds/738227/) · [群体齿音录音](https://freesound.org/people/ShangusBurger/sounds/763804/)
- 一条 FLEURS 真人普通话朗读用作语音保护对照。另用两条不同的真实录音作为背景，与同一段 Rap 人声构造两份可复核的重混：真鼓相对人声为 +6.00 dB RMS，实录人群相对人声为 −9.00 dB RMS。[重混脚本](../tests/mc_corpus/mix_controls.py)
- 0.1.0 在独立进程中直接加载已交付源码 ZIP，SHA-256 为 444455fd3e2cb5a5300131e277c29428a4eca39c4b297c55cdbaae0a35339844。0.1.1 在另一个进程加载冻结源码快照，SHA-256 为 59e15c5d6cec6a022c46ac10e17c84d16dddcee27bf289f536bdab1295d0042a。两版同时使用开发环境中固定的编解码器，分别通过各自的窗口参数生成逻辑、应用服务和 DSP 渲染整轨。各原文件的 SHA-256 在渲染前后核对一致。

## 盲听素材质量

28 组共 84 份 24-bit WAV，各组原音、0.1.0 和 0.1.1 的时长及采样位置一致。仅用常量增益匹配，然后重读文件，用 FFmpeg C 语言 ebur128 滤镜独立测量。在极安静片段中，绝对响度门限会因增益改变纳入统计的帧，因此脚本允许再次调整同一常量直到达标。此次每组最大响度差为 **0.003 LU**，84 份文件中最高真峰值为 **−3.39 dBTP**。28 个区间的新旧输出均有实际采样变化。分项人耳评分仍待收集，已获得的用户偏好独立记录。[统一试音办法与已签收答复](LISTENING-011.md)
