# VoxMaster AI 项目审计记录（2026-11-19）

> 本记录来自当前工作区、Git 历史、可执行测试和 GitHub API 的真实结果。它是审计快照，不把“已构建”“已测试”和“待人工验收”混为一谈。第 3 节的工作区状态是本轮改动前的基线；本轮实施的修复见第 9 节。

## 1. 项目与仓库现状

- 产品：VoxMaster AI，本地离线人声/喊麦调音工作站；核心定位未改变。
- 工作区：Python 3.11 + PySide6/Qt Widgets、NumPy/SciPy、PyAV/FFmpeg、PortAudio、ONNX Runtime。
- 当前本地版本：`0.3.1`，由 `vox/__init__.py`、`packaging/VoxMasterAI.iss` 和 `packaging/version.txt` 统一校验。
- Git：`main` 与 `origin/main` 对齐；远程为 `git@github.com:yuchen0x1/VoxMaster-AI.git`；已有标签 `v0.1.1`、`v0.3.0`、`v0.3.1`。
- 主要交付形态：Windows x64 安装器/便携包；Linux/macOS 为源码与 CI 试验支持；CLI 与桌面共享音频服务。
- 未改变授权声明：仓库没有新增整仓开源许可证；Qt、FFmpeg、PortAudio、ONNX Runtime、模型和测试音频的第三方许可仍按 `docs/THIRD_PARTY.md` 管理。

## 2. 代码与数据流摘要

桌面进程由 `app.py` 启动，Qt 窗口在 `vox/interface.py` 等模块中实现；`vox/service.py` 负责会话与渲染编排，`vox/jobs.py` 负责可取消后台任务，`vox/audioio.py`/`vox/playback.py` 负责解码、重采样、导出和监听。`vox/analysis.py`、`vox/acoustics.py` 产生可解释测量；`vox/engine.py`、`vox/pitch.py` 执行调音；`vox/models_store.py`、`vox/models_runtime.py` 管理固定版本模型、哈希、推理进程及 CPU 回退；`vox/storage.py` 与 `vox/studio_*` 管理工程、多轨与原子保存。

数据默认留在本机用户数据目录；工程采用相对素材路径、版本化 JSON 和备份。更新通道读取 HTTPS 的 GitHub Release 清单，验证 Ed25519、大小与 SHA-256 后才允许启动交互式安装器。自动静默安装、自动回滚、远程遥测不在当前范围内。

## 4. 平台结论

- **A：Windows 11 x64、CLI**：核心功能与当前发行链匹配。Windows 10 仍需真实设备验收，不宣称通过。
- **B：Linux x64（Ubuntu/Debian/Fedora/Arch 源码路径）、macOS Intel/Apple Silicon 源码路径**：共享核心与 CI 可行，但监听设备、安装包、签名/公证尚未完成实体验收。
- **C：Android、Android 平板、折叠屏、iOS、iPadOS、桌面/移动 Web、响应式 Web、PWA、Docker、NAS、私有化、云服务器**：需要重做音频运行时、权限、触控或服务端模型，当前投入产出比不足，暂不开发。
- **D：Chrome/Edge/Firefox 扩展**：扩展权限和运行时不能完整承载离线 DAW/模型核心，不开发。

详细平台限制以 `docs/PLATFORMS.md` 为准；A/B 是投资决定，不等于已发布或已验证。

## 6. 主要风险与未完成事项

1. **Windows 10 实机验收缺失**：安装、卸载、DPI、音频设备和模型路径需在真实 Win10 设备补测。
2. **安装器未 Authenticode 签名**：更新清单签名不等于系统级代码签名；证书和发布审批仍需维护者配置。
3. **Linux/macOS 未提供已验收安装包**：不得把源码 CI 通过写成 DEB/RPM/AppImage/DMG 已发布。
4. **自动回滚未实现**：更新失败只能保留旧目录/重新安装，需安装器级设计后再做。
5. **模型回归未在本次环境完整执行**：125 项中 2 项因未设置真实权重跳过；发布前应在权重可用的专用环境执行并保存证据。
6. **开发虚拟环境不完整**：`.venv` 没有 pip；按 README 重建环境后再运行依赖审计，避免把开发环境问题带入发布环境。
7. **版本/Release 漂移窗口**：发布工作流已验证 v0.3.1 资产与更新清单；今后仍应保留标签→公开 Release→清单核对，避免新版本在短暂窗口内提前对外宣称。
