# 使用手册

## 从录音开始

导入时保持原文件不变。时间轴上方为原音，下方在渲染完成后显示成品。两条波形共用时间刻度。工作台右侧显示当前 A 或 B 的测量值。点击「完整分析报告」查看频带分布、动态、音高稳定性、尾部衰减和工程操作记录。

第一次处理建议选择「经典喊麦」。一键调音会按当前录音的频带功率、活动电平、动态、噪声和停顿调整所选风格，再对成品进行质量复测。选择新的风格后再次点击调音即可试听。密集伴奏可能影响类型判断，录音类型可在右侧手动指定。

## 试听与调整

点击时间轴定位，拖动选择区间，开启「循环」可反复听同一句。空格切换播放或暂停。播放中点击 A 或 B 在相同时间位置比较，开启「等响试听」会衰减两者中综合响度较高的一侧。监听音量与等响设置只影响播放。右键时间轴可清除选区或打开多轨编辑。

从「调整效果器与链路」进入详细参数。EQ 可调高通、频率、增益与带宽，压缩器可调阈值、比率、软拐点、起落时间与补偿。测量页结合原音片段查看参数产生的增益衰减。拖动链路项目调整处理顺序，取消勾选可旁通模块。最后的峰值保护会对输出再次检查。

旋律修正适用于清晰的单声部。选择调性、音阶以及适度的力度，优先听齿音、转音和辅音衔接。空间效果可以手工更改类型、衰减、阻尼和湿声。智能尾音根据持续发声和停顿生成可编辑的时间点，按秒添加、选择或删除。发送到原轨末尾之后的效果尾部会被截在现有音轨边界内。

## 参考匹配、预设与分轨

0.1.1 的「时间分段」页显示每段的时间、推测类型和置信度。选中一行可查看具体证据、限制并定位试听。进入参数窗口的「分段参数」页，可修改低中频、清晰度、高通、齿音、压缩阈值、比率、瞬态保留、降噪和空间发送。个人预设只保留可复用于其他录音的设置，区间编辑随该工程保存。

渲染后打开「完整分析报告 → 效果器实测」，选降噪、均衡、压缩或齿音控制。按钮会取时间轴选区或游标附近最多八秒，用当前工程参数重新渲染并对比该模块的输入和输出。两个试听按钮共享进度，响度对齐只作用于监听。很短的区间及从中途开始的滤波器、压缩与混响存在启动效应，整曲决策请回到时间轴试听。音高曲线选区、尾音伸缩和后一句避让见[编辑示例](PITCH-TAIL-011.md)。

参考匹配可按六种段落角色选择，两条录音长短可以不同。范围数值可作为调节起点。点击区间试听，可在同一段人声上比较同风格的基础调音与参考匹配处理。当两条录音均有衰减或回声证据时显示测得的时间差。点击「恢复匹配前参数并移除参考」可以返回首次应用前的状态。

「参考匹配」可导入一段参考作品，查看两者的响度、频带、动态和空间测量，点击匹配后据此渲染。对完整混音执行参考匹配时，伴奏也会影响测量。预设库允许复制内置风格、保存当前调整及交换 .voxpreset 文件。与某条录音绑定的尾音时间点保存在工程里。

## 0.4.0 工作模式：独立人声、整曲与多轨

导入前可在工作台顶部选择 **独立人声调音 / 完整歌曲整曲处理 / 多轨专业工作站**。模式显式记录到工程；音频频谱、宽度或 LUFS 不会替用户判定素材属于人声还是混音。选择错误可随时切换。独立人声使用原有人声链。多轨模式只打开现有工作室，不会自动分轨。

完整歌曲模式支持整曲立体声歌曲。先点击「整曲处理…」打开确认项，选择人声风格、整曲目标（自然还原、人声靠前、力量冲击、清晰通透、厚实饱满）和保守/标准/增强母带，再选新分轨目录。只会使用已安装且文件大小/哈希校验通过的本地 Spleeter 模型；缺模型时由用户选择打开模型中心，不在后台下载。保留原始输入，分轨先生成到同盘临时目录，分析/渲染/导出分轨成功才发布。取消或失败不会覆盖之前的音频。

复核已生成方案可精确调整人声/伴奏增益、伴奏低中高频，以及 LUFS 与真峰值上限。综合 LUFS、源真峰值及动态范围约束母带增益；源响度与峰值目标冲突时保护余量优先，成品可能达不到响度目标。整曲人声默认不做二次降噪、音高修正、饱和或空间增强，以免重复处理源混响、压缩和分离伪影；试听满意后再选择标准或增强母带，注意动态变化。再次点击方案入口会显示当前参数，修改后可撤销。

分离后的 Vocal / Instrumental 可在「专业混音」中手动剪辑；工作室显示已经处理过的分轨。应用工作室效果后，最终整曲母带在多轨总线之后进行。整曲报告中的响度、真峰值和重建误差是客观测量；**人声泄漏、分离伪影与听感质量必须人工等响试听**，仅凭人声+伴奏可重建原曲不能判定质量。[0.4.0 实际歌曲测量与限制](AUDIO-040.md)。

导入完整混音后也可以使用单独的「人声分离」动作。首次使用从模型中心下载；模型准备好后选择输出目录。完成后可进入多轨工作室。设备、下载、权重授权限制见[模型说明](MODELS.md)。片段编辑和同步试听见[多轨手册](MULTITRACK.md)。

## 保存、恢复与导出

Ctrl+S 保存，Ctrl+Shift+S 另存，Ctrl+Z 撤销，Ctrl+Y 重做。工程以路径引用素材，同磁盘尽量使用相对路径。移动工程时请一起移动素材。打开工程遇到丢失文件，可以选择替代文件并保存工程。每次应用变更时自动保存一份恢复记录，重新保存到已有工程时保留上一个版本。在「我的项目」中打开最近项目、恢复记录或当前工程的历史版本。

导出 WAV 可以选 16-bit、24-bit 或 32-bit float，FLAC 可以选 16 或 24 bit，AAC、MP3 使用有损编码。导出窗口显示渲染总线的 LUFS 和真峰值及预计体积。有损编码、重采样、改为单声道可改变最终响度与峰值。需要核对编码后电平时，把成品重新导入查看。每次导出需要新的文件名。Ctrl+E 打开导出，Ctrl+Enter 执行一键调音。

## 外观与键盘操作

在「设备与设置 → 外观」选择 **跟随系统 / 浅色 / 深色**。更改会立即预览，点击「保存设置」后在下次启动继续使用；取消或关闭设置会还原进入前的主题。系统主题变化只在选择「跟随系统」时应用。应用内容区、图表和自有菜单共用主题；操作系统窗口标题栏及原生文件选择器由系统管理。

工作台时间轴支持左右方向键每次定位 0.1 秒、Ctrl+方向键每次 1 秒、Home/End 跳到首尾，Shift+方向键扩展试听选区。空时间轴按 Enter 可导入。多轨时间轴支持左右方向键定位、Shift+方向键加速，原有 R 数值选区、剪辑快捷键继续可用。EQ 和音高选区也能通过对应数值字段编辑，不必拖动图表。

窗口较小时，导航、编辑区和较长的设置页可滚动查看；长工程/素材标题会省略显示，悬停可读完整内容。界面改造不改变音频、工程格式或导出规格。

## 设备与数据

设置里可修改监听设备、工程、导出及音频缓存目录。模型迁移在模型中心操作，会校验复制件。默认配置、自动保存和模型位于 %LOCALAPPDATA%\VoxMasterAI。项目和成品位于保存时选择的目录。超过内存缓存阈值的导入会使用临时磁盘映射，渲染和模型分离仍需要与音轨长度相关的内存。任务进行时仍可播放已有缓冲、检查报告或查看预设。取消会保留当前已完成的工程状态。
