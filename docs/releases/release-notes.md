# VoxMaster AI 版本记录

## 0.3.2 · 2026-11-19

修复音频文件保护、多轨编辑、窗口资源释放和发布质量门禁。建议 0.3.0/0.3.1 用户更新。

- CLI 报告在分析或渲染前检查全部输入与计划输出，拒绝同路径、硬链接等别名冲突；报告改为原子写入，写入失败保留旧文件并返回非零状态。
- 修复多轨片段移动到相同副本时丢失前序撤销记录的问题，移动作为一次事务提交，保留 80 条历史上限语义。
- 启动先读取上一会话状态，再记录本次启动，首次启动及正常退出后重启不再误报异常。
- 关闭模态窗口和右键菜单后释放原生对象及旧音频引用，保留读取返回值和试听任务安全收尾的顺序。
- 工程读取校验嵌套字段类型，损坏工程显示明确错误，并保留 v1 工程缺省字段与相对路径兼容。
- 包验收改用显式检查，Python 优化模式下仍会拒绝失败结果；修正分钟交界处显示为 60 秒的问题。
- 修复 pytest 收尾将失败状态变为退出码 0 的问题，增加独立进程的通过、失败、收集错误、零用例和参数错误回归。
- 分支治理比较绑定确切提交 SHA，删除使用 expected-SHA 租约；分支更新时拒绝删除，保留年龄、保护分支、Dependabot 与开放 PR 保护。
- 补充 56 个回归用例；本地最终集成按独立 testcase 节点统计为 183 通过、3 跳过。两项模型测试缺少真实权重，另一项受 Windows 文件符号链接权限限制。

Windows 安装器仍无 Authenticode 签名，自动回滚未实现；Linux/macOS 仍为源码与 CI 试验支持。真实模型权重、实体监听设备及安装升级验收的边界见 [修复记录](../BUGFIX-2026-11-19.md)。

## 0.3.1 · 2026-11-19

工程维护版本：产品代码与 0.3.0 完全一致，无用户功能变化。

- CI 的四个 GitHub Actions（checkout 7.0.1、upload-artifact 7.0.2、setup-python 7.1.0、dependency-review 5.0.0）完成主版本升级；本次发布即经真实流水线验证新配置。
- 新增每周分支治理工作流（`scripts/branch_governance.py`）：自动分类远程分支、报告需要人工决定的分支，只清理完全包含于 main 的分支；自动合并明确排除在外。
- Dependabot 加入 numpy≥2.5、scipy≥1.18、mpmath≥1.4 的 ignore 规则（需要 Python 3.12+ 或受上游 sympy 约束）。

更新说明：0.3.0 用户可以跳过此版本；更新后产品行为与 0.3.0 完全一致。

## 0.3.0 · 2026-11-19

- 修复 GitHub Actions 工作流配置错误（`runner` 上下文在作业级环境不可用），此前推送会触发全部工作流无日志启动失败；CI 现包含 actionlint 工作流静态校验，防止配置回归。
- 新增本地会话健康检查：程序异常退出或断电后，下次启动显示温和提示；标记仅保存在本机数据目录，无遥测。
- 命令行新增 `styles` 子命令与 `--report` 参数：自动化可直接读取风格清单和完整 JSON 报告文件。
- 官方更新窗口在下载前展示安装包大小与 SHA-256 摘要前缀。
- 发布工作流新增发布后验证：重读公开更新清单并逐资产核对链接；月度维护扫描新增近 90 天上游提交活动。
- 保留既有调音、分离、多轨、参考匹配、工程格式与更新校验机制。

Windows 安装器仍无 Authenticode 签名；自动回滚未实现。Linux/macOS 仍为源码与 CI 试验支持。本轮改动依据 37 个上游项目近 90 天活动调研，见 [RESEARCH-030](../RESEARCH-030.md)。

## 0.2.0 · 2026-11-18

- 新增官方更新窗口，可查看发布说明、下载进度并校验官方数字签名，下载完成后启动 Windows 安装器。
- 新增离线命令行分析和多文件批量调音，输出 JSON 结果，已有文件受到保护。
- Linux 与 macOS 源码环境使用各自的用户数据目录、系统字体和 CPU 推理依赖，进入原生 CI 试验支持。
- 保留现有一键调音、音高与尾音编辑、人声分离、多轨混音、等响试听及工程格式。

Windows 安装器尚无 Authenticode 签名；自动安装回滚未实现。Linux/macOS 未发布安装包，实体音频设备与安装生命周期需另行验收。
