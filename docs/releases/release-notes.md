# VoxMaster AI 版本记录

## 0.5.1 · 2026-11-21

工程与后台任务可靠性维护版本，建议使用多轨外部素材、模型迁移或工程历史恢复的用户关注。

- 外部音轨使用内容 SHA-256 与文件签名共同决定 PCM 缓存复用，处理结束前再次校验；同尺寸/同时间戳替换不再导致重建与重开声音不同，外部同名引用不能遮蔽内置人声/伴奏。
- 新生成的 `.history` 备份相对于实际目录保存素材引用，随整个工程树搬迁后仍可恢复；跨盘使用绝对路径，已有备份继续兼容，不自动改写旧备份。
- 同时持有两把模型目录锁后重新核验源，默认安装/删除也在持锁后复核活动目录，拒绝另一实例已完成迁移的过期操作；显式指定目录仍兼容，不再将活动目录指向空位置。
- 工程文件/恢复点保存成功与最近工程设置保存失败分开提示；真正的工程写入失败仍保留现有事务保护和错误反馈。
- 官方更新检查响应取消，关闭等待线程收尾，忽略晚到成功回调；下载最后一块后也检查取消，不发布取消任务的缓存文件。
- 自定义清单检查支持协作取消、重入保护与过期结果隔离；设置窗口关闭后不继续更新 UI。
- 源码归档采用正向白名单及路径/固定资源校验，清单兼容 LF/CRLF、支持再次归档；公开清单与旧文档中的私人素材文件名改用中性编号，不修改音频或 Git 历史。
- “我的项目”入口对最近记录只读筛选，隔离权限错误与消失文件；附属设置损坏时仍能打开有效恢复点，不自动改写原设置。
- 源码遍历前剪除 Windows junction/重解析点及私人目录，拒绝根内别名与循环；安装/便携文档使用独立正向清单和离线索引，未知研发证据不入包，文件系统发布失败可回滚。
- 叠加淡入/淡出使用有界包络乘积近似，不再只连接零端点导致静音；保持 v1 线性节点格式，复杂度超限不改会话及撤销/重做。
- 导出落盘后晚到取消仍返回真实成功收据；整曲 CLI 母带编码失败时返回已保存的 `stems` 与 `recovery_project`，错误退出码保持非零。可选会话诊断写入失败不再阻断启动或覆盖正常退出码。
- 不新增运行依赖或模型，不更换默认人声 DSP 链、默认音色、导出规格和 `.voxproj` v1。淡变修复纠正编辑结果，不宣称主观音质提升；确定性离线与 Qt 回归不依赖私人歌曲或真实网络。

**安装/升级：**使用本版本官方 Windows x64 安装器覆盖安装，或将便携 ZIP 完整解压至新目录再启动。用户数据位置不变；升级前保存工程并备份素材。Linux/macOS 仍为源码/CI 试验支持。

**已知限制与发布状态：**Windows 10 实机、实体设备热插拔和 Authenticode 签名仍未验收/完成；完整渲染仍需与时长、轨数有关的内存。签名更新清单不等于 Windows 程序签名。未重新证明主观音质提升；本版本正式公开仍须有本版本人工等响听审批准、限制接受及隔离安装验收。不得沿用 0.5.0 的批准冒充 0.5.1；远程 Release/工作流才是发布状态依据。

本地最终整合回归为 603 通过、3 项 Windows 文件符号链接权限跳过；真实模型、公开夹具 GUI 恢复/调音/正常退出和隔离 0.5.0→0.5.1 升级已执行。QA 安装器在较深目录重编仍失败，同一实际资产转到新的物理短目录后通过；不把绕行当原路径全修复。模型中心上游检查慢响应期间关闭受阻仍为已知 P2，详见交付报告。

## 0.4.0 · 2026-11-20（本地候选，未公开发布）

**AI-Powered Vocal Production & Music Mixing Workstation**。本轮以现有成熟模块为底座，补齐整曲工作流，而非重写 DAW 或引入云端上传。

- 三个显式入口：独立人声、整曲处理、多轨混音。选择与修改可保存/撤销，不靠简单音量或频谱阈值强行分类。
- 共用 `Audio Intelligence` 测量：保留源格式/声道，与内部 44.1 kHz 立体声 PCM 分开；综合/短时 LUFS、RMS、4× 真峰值、动态、频谱和相关性不被混称为语义 AI。
- 完整歌曲：本机固定 Spleeter 双轨 → 保守人声链和伴奏 EQ/电平 → 现有 Studio 总线 → 最终母带 → 质量复测 → A/B 与无损/有损导出。只用既有或用户确认下载的模型，音频不离开本机。
- 方案可精确编辑，切换标准/增强母带后只改 LUFS/峰值仍保留算法力度；人声层强制旁通母带，避免总线前后重复处理。
- 原始分轨只在整条处理成功后发布；发布前取消清理、发布后晚到取消交付结果。素材 SHA-256 绑定分离证据，替换素材使旧结论失效；恢复保存失败保留旧会话和撤销历史。
- `.voxproj` v1 继续兼容；外部分轨允许不同尾长；带非中性歌曲处理与多轨剪辑的保存/重开逐采样一致。
- CLI 新增 `song`，共用同一服务。保护输入、输出、权重、模型配置/锁/断点文件，保存 JSON 与本机验收证据。
- MIT LICENSE 同步 README、安装文档和源码包。未增加运行依赖、商业 SDK 或模型权重；私有音频不进发行包。
- 发版标签默认只构建候选，正式公开需显式手动确认、听审批准与已知限制接受，并先做隔离安装验收；签名资产暂存拒绝残留混入，公开复核拒绝把 CDN 旧版清单当作当前版本。

本轮自动化结果 **417 通过、1 跳过**，两首指定完整歌曲在真实 DirectML 下完成处理并回读；**这不代表主观音质已验收**。独立模型、真假嗓/情绪语义、时间对齐的 AI 掩蔽建议、多版本 A/B/C、VST3、长音频全链路流式化仍未完成。Win10 实机、实体设备热插拔、人工等响听审和 Authenticode 签名为剩余门禁。安装/便携/升级结果与文件位置以 [交付报告](../DELIVERY-040.md) 为准。

## 0.3.2 · 2026-11-19

修复音频文件保护、多轨编辑、窗口资源释放和发布质量门禁。建议 0.3.0/0.3.1 用户更新。

- CLI 报告在分析或渲染前检查全部输入与计划输出，拒绝同路径、硬链接等别名冲突；报告改为原子写入，写入失败保留旧文件并返回非零状态。
- 修复多轨片段移动到相同副本时丢失前序撤销记录的问题，移动作为一次事务提交，保留 80 条历史上限语义。
- 启动先读取上一会话状态，再记录本次启动，首次启动及正常退出后重启不再误报异常。
- 关闭模态窗口和右键菜单后释放原生对象及旧音频引用，保留读取返回值和试听任务安全收尾的顺序。
- 工程读取校验嵌套字段类型，损坏工程显示明确错误，并保留 v1 工程缺省字段与相对路径兼容。
- 包验收改用显式检查，Python 优化模式下仍会拒绝失败结果；修正分钟交界处显示为 60 秒的问题。
- 修复 pytest 收尾将失败状态变为退出码 0 的问题，增加独立进程的通过、失败、收集错误、零用例和参数错误回归。
- 分支治理比较绑定确切提交 SHA，删除使用 expected-SHA 租约；分支更新时拒绝删除，保留年龄、保护分支、Dependabot 与开放 PR 保护。
- 补充 56 个回归用例；本地最终集成按独立 testcase 节点统计为 183 通过、3 跳过。两项模型测试缺少真实权重，另一项受 Windows 文件符号链接权限限制。

Windows 安装器仍无 Authenticode 签名，自动回滚未实现；Linux/macOS 仍为源码与 CI 试验支持。真实模型权重、实体监听设备及安装升级验收的边界见 [修复记录](../BUGFIX-2026-11-19.md)。
