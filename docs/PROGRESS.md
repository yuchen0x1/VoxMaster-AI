## 验收边界

- 现版人声类型依赖声学特征。近似 Rap、语音喊麦、演唱或混合伴奏的信号可能互相混淆，低置信度时可手动指定。模型中心目前验证了 Spleeter 2-stem；基础降噪、分析、音高修正和增强使用本地算法。
- 音高修正以清晰、稳定的单声部片段为目标。复调主唱、重伴奏、双人交叠、共振峰自然度与极端移调均需专项听审。参考匹配无法由整轨频带统计精确反推混响器型号、人声与伴奏的真实比例。
- Windows 11 本机完成实际输出设备和 DirectML 加速验证。独立 CUDA 环境、Windows 10、长时间跨设备运行与人耳偏好尚待验收。
- 版本检查支持用户配置的 HTTPS 清单。官方软件更新服务、Authenticode 签名和外部分发尚未建立。权重单独商用分发许可的核查状态见 MODELS.md。
