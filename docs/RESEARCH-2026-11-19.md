## 研究方法与边界

本轮只纳入可打开的上游仓库、官方 README/LICENSE、GitHub commits 或官方产品页；不把无维护 fork、安装脚本或自动 CLA 提交当作功能证据。活动日期来自 GitHub commits API 采样（Asia/Shanghai 2026-11-19）；“最近提交”不等于最近发布功能。代码许可证与模型/权重/训练数据许可证分开记录，不能由 MIT 代码推断权重可商用。本轮得到 13 个可核验开源项目和 5 个商业市场参考；领域内大量相似 fork 因许可证、维护状态或源码不可核验而剔除，没有为了凑足 30 个而降低证据门槛。

## 本轮吸收决定

- **实施/已覆盖**：模型固定版本+SHA-256、CPU/DirectML 回退、批处理 JSON 报告、更新签名清单、分支治理安全检查、平台功能矩阵与真实状态文档。
- **近期实施候选**：诊断包与模型注册字段、Windows 10 实机矩阵、音频设备热插拔、SBOM/许可证清单自动化、严格工程 JSON schema。
- **暂缓**：实时变声、VST3 宿主、RVC/RMVPE/Whisper 集成、社区模型仓库、Linux 原生包、自动回滚。原因是核心定位、许可证/权重风险、设备与证书缺口或维护成本。
- **禁止直接移植**：任何竞品品牌、图标、素材、未知来源代码和不明许可证模型；只吸收可解释的设计/算法思路并保留相应通知。
