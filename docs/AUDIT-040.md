## 关键结论

1. **可复用面比预想大**：分离、多轨混音、等响监听、工程持久化都已存在。0.4 没有重写它们，而是补上“统一分析入口 + 歌曲级处理层 + 模式路由”。
2. **最危险的不是缺功能，而是边界**：分轨在渲染成功前就对外发布、会话提交与自动保存不同步、恢复文件被当作普通工程保存。这三处会制造“看起来成功”的假象，本轮优先处理。
3. **旧判断不能冒充 AI**：现有分类器对真实整曲返回“其他/不确定”。0.4 不再用音量/高频阈值自动决定路由，而是显式要求用户选择模式，并把手动纠正作为正常路径。
4. **许可证是发布阻断项**：根 LICENSE 为 MIT，但 README 与发行物未同步。第三方权重（Spleeter 转换权重）仍有独立条款，不能用项目 MIT 覆盖。
5. **真实素材已可用**：两首参考歌曲在本机桌面可直接读取（详见 [AUDIO-040.md](AUDIO-040.md)）。它们只用于本机验收，输出写入被忽略的 `.audit/`，未上传、未提交、未用于训练。
