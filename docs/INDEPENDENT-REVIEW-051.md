# 0.5.1 并行独立审阅与补充修复

核验日期：2026-11-21（本地 UTC+08）。这是本轮独立审阅的实证记录，不是正式发布成功声明。另一个并行会话负责原有五项 0.5.1 修复；本会话不覆盖其工作区、暂存区或版本发布操作。

## 1. 本轮升级概况

- 项目：VoxMaster AI，本地优先的喊麦人声制作、整曲分离处理和多轨混音桌面工作站。
- 原正式版本：启动时通过 GitHub Release API 核验为 v0.5.0；默认分支为受保护的 `main`。
- 本轮候选：0.5.1；最终版本、提交和发布以远程核验为准。
- 目标：修复设置页自定义版本检查的生命周期缺陷，收紧源码发行文件选择；独立复核已有数据完整性修复。不改变 DSP 算法、工程 schema 或用户音频。
- 并行保护：启动时已有 `service.py`、`updating.py`、`update_dialog.py` 修改和四个未跟踪测试。已备份，未覆盖、重置、清理或擅自纳入本会话提交。

## 3. Bug 修复

### 本会话：设置检查生命周期

`vox/settings_dialog.py`：

1. 检查启动前、流式读取中及响应结束后检查取消信号；上下文退出关闭响应。
2. 设置对话框保存成功、取消或关闭时取消任务并停止轮询定时器；设置验证失败不误取消任务。

#### 客户端无法解决的问题
