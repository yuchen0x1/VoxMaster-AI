# 音高与尾音编辑

在处理参数窗口打开「音高与尾音编辑」，拖动音高曲线或用起止时间选区，填写半音、响应速度和贴音力度，点击「写入选区音高」。同一选区再次写入可更新参数。「撤销编辑」逐步还原本次窗口内的操作。A 播放原始片段，B 在工作线程渲染当前音高与空间链路并绘制实测基频。试听按原音响度调整 B 的监听增益并预留峰值余量；导出不使用这个监听增益。点击「应用」后，编辑随工程参数保存。

选中检测到的句尾，设置延长或缩短比例、发送电平、回声次数、延迟与混响发送，再点击「写入选区尾音」。左右交替、立体声和拍点同步等路由复用现有空间参数。程序测量局部能量、句间低能量区、后续起音和拖腔末端的音高稳定性。选区限于五秒以内，可在原始时轴的空隙中延展至两倍。在下一句前预留淡出，在轨道末尾限制延伸长度。没有足够停顿时可选择缩短或移动选区。整轨伴奏可能遮蔽句间停顿，建议在分离后的人声上定位。

「试听下一句」包含本句尾部和后续起音，并测量下一句起点后 150 ms 中，所选尾音发送的 RMS。此值单独计算；全轨连续混响、有声伴奏及前期已经录入的空间声可能继续出现在成品中。

## 算法与边界

- 基频候选来自短时归一化自相关。周期性、声道侧向能量和相邻帧变化共同约束可用帧，单帧低置信度的八度误判仅在两侧基频一致时修复。稳定乐音以局部周期为单位取样并重叠相加，以保留局部谱包络；无声、不规则周期和突变交界处保持原声。人工选区可以覆盖段级旋律保护，仍受周期证据限制。居中伴奏或合唱无法始终与主声基频区分。[Moulines 与 Charpentier 的音高同步方法](https://researchportal.ip-paris.fr/en/publications/pitch-synchronous-waveform-processing-techniques-for-text-to-spee/)
- 尾音伸缩在左右声道使用相同的波形对齐位置，依据局部归一化互相关选择相邻合成帧，保留采样时钟及下句位置。极短选区不能作可靠的声学判断。[Roelands 与 Verhelst 的 WSOLA 研究](https://www.isca-archive.org/eurospeech_1993/roelands93_eurospeech.html)

## 本机验收

| 素材 | 结果 |
| --- | --- |
| 真人普通话朗读 10.38 秒 | 选中 2.176–2.354 秒，手工上移两半音。在可复测的四帧中，基频位移中位数为 2.027 半音，选区外逐样本一致。3.06–3.24 秒尾音指定 1.5 倍伸缩并发送空间效果，下一句 3.98 秒起始后 150 ms 最大差值为 0。 |
| 本机喊麦成品 45–57 秒 | 598 帧中 16 帧得到可用周期。低证据的混音保留原有音高；这段持续伴奏无足够的静音间隔，检测未生成句尾。 |
| 同一录音的模型估计人声 | 有 132 个可用周期帧。稳定区 1.756–1.874 秒手动上移两半音，可复测的三帧实测中位数为 1.658 半音。跨越声区的短段测得 0 半音。保护和速度平滑会降低短片段的实际位移。 |
| 可控音频与原生控件 | 覆盖 0.65 / 1.65 倍时间伸缩的帧数、基频、编辑边界、单声道与双声道路由、下一句避让、重复数为零、声区跳跃、无声与噪声保护、三秒试听参数裁剪，以及原生曲线拖选、撤销、A/B 渲染。 |

专项素材库另有 VocalSet 的带标签气声与持续长音，以及单一假声录音。中文喊麦原始干声与同一演唱者的真假嗓切换边界仍缺少独立标注。上述真实录音的基频复测使用本程序的检测器，自然度、共振峰听感与跨声区表现仍需独立听审。[素材覆盖表](AUDIO-011.md)
