# 0.5.1 发行产物暴露面核验

核验日期：2026-11-21（本地 UTC+08）。对象是本仓库自行构建的 Windows PyInstaller 产物，不是第三方产品逆向。检查只读取文件；没有执行扫描到的归档内容，也没有向外部服务上传音频或二进制。

下文保留前期 0.5.1 快照的 native 画像与误报复核，不代替后续整合验收。最终整合又修复根内 junction 别名及安装/便携文档递归选取：新的 package 画像为 483 文件、241 二进制，启发式零发现，但 **241 项 binary 检查未执行**，不与下文 native 原始告警混算为“漏洞全消除”。精确包内容、已知私人标识检查及剩余风险见 [最终交付安全小节](DELIVERY-051.md#安全暴露面复测)。

## 1. 总览

本项目以 MIT 许可公开源码，主要价值是本地工程实现，不以客户端代码保密或付费授权保护为目标。因此“可解包/接近开源”不能当作已被入侵。扫描器的原始分数 **0/100、D** 是启发式暴露评分，不是漏洞风险定级或绝对安全证明。

- 原始基线：524 文件、240 二进制。
- 0.5.1 修正后 Freeze 产物：470 文件、241 二进制；复制发行文档后的最终目录为 **573 文件、241 二进制**。两个阶段分别留有原始收据，不混用扫描规模。
- 最终目录与原始基线按同配置比较：无新增、加重、改善或消除的发现编号；主要告警来自相同第三方运行库。数量变化不能解释为修复全部暴露面。
- pip-audit 2.10.0 审计 31 个适用锁定依赖，返回已知漏洞列表为空；这不是零漏洞保证。
- 保留的真实限制：未 Authenticode 签名；第三方 PDB/构建路径和 CFG 差异；PyInstaller 可解包。
- 原始“私钥/Token/备份”严重告警经下述有限复核，未确认为实际秘密泄露。不能仅凭正则未匹配便保证不存在任何秘密。

本地证据位于 `.audit/evolution-051/` 下的 `exposure-baseline.json`、`exposure-final.json`、`exposure-package-final.json`、`exposure-final-triage.json`、`archive-final-verification.json` 和 `dependency-audit.json`；不公开带本机绝对路径的完整原始扫描日志。

## 3. 逐项证据与修复

### 系统签名、调试与原生加固

`VoxMasterAI.exe`、`VoxMasterAI-CLI.exe` 和依赖属于正常可分析的本地客户端。当前安装器没有 Authenticode，可能触发系统信誉提示；不能宣传为系统签名发行物。真正修复需可信代码签名证书、时间戳和受控 CI 凭据，涉及证书/费用时先取得授权，不能生成自签证书冒充可信签名。

PDB 与构建路径要按 PE 来源定位：自行编译部分可在编译/链接时使用路径映射、可重复构建与适当符号管理；第三方 wheel/DLL 不应事后随意改字节、删除许可或破坏其已有签名。CFG 必须在编译工具链正确启用并实测，不能简单篡改文件头当作修复。

### “私钥”与“GitHub Token”的有限复核

以下文件有 PEM 标题字符串，但独立复核未匹配到由完整标题、Base64 多行正文及配对结束标记构成的标准 PEM 私钥块：

- `_internal/PySide6/Qt6Network.dll`：0 块。
- `_internal/PySide6/plugins/tls/qopensslbackend.dll`：0 块。
- `_internal/PySide6/plugins/tls/qschannelbackend.dll`：0 块。

这是对具体误报的有限证据，不覆盖 DER、加密容器、非标准 PEM、运行时秘密或全部字符串。未把任何命中的潜在秘密原文写入公开报告。

`_internal/scipy/optimize/_highspy/_core.cp311-win_amd64.pyd` 中 `ghs_` 命中偏移为 **5,545,739**，上下文确认是 `ghs_setCallbackP5HighsSt8function` 开头的 C++ 回调符号。扫描器把符号前缀当作 Token；无需删除 SciPy 或改写第三方二进制。

### 归档与客户端代码

`ThirdParty/Qt-notices.zip` 共 178 项，是许可/元数据及相关通知；`_internal/base_library.zip` 共 155 个 `.pyc`，是 Python 运行库。它们不是数据库转储。保留必需运行库和合法再分发材料，不为分数做破坏性“清理”。

便携包的 `_internal/certifi/cacert.pem` 是 HTTPS 使用的公共 CA 证书集合，不是私钥。复核确认其 SHA-256 与固定运行环境中的 certifi 文件完全相同，且可按 X.509 证书集合解析、没有 PRIVATE KEY 标记；只为这一精确路径和哈希放行，不放行任意 `.pem`。审计解析器对集合内既有非正序列号证书给出了未来兼容性警告，已保留；这不等于所有证书链或未来解析兼容性均已证明。

PyInstaller 包可以拆出字节码是预期；MIT 开源程序没有必要为阻止合法审阅加入强反调试、无益混淆或云端音频处理。源码包仍必须排除私人媒体、模型权重、缓存与凭据；扩展名白名单也不是文本敏感信息识别器，允许的文档仍需内容审阅。

### 私人素材元数据

人工交叉复核发现通用扫描器没有理解的真实隐私边界：源码清单、README 和旧验收文字保留了私人素材文件名。已将五个本地语料条目的 `file` 改为稳定编号加原扩展名，并脱敏两份文档；保持 id、类型、授权说明、测量和本地私有指纹校验要求，不修改或上传音频。原始清单和临时脱敏映射只保留在被 Git 忽略、发行范围之外的 `.audit/`。

不能只在手工源码 ZIP 中转换清单：GitHub 自动生成的 Tag 源码包不会执行打包脚本，因此已跟踪清单本身也必须去标识化。新增五个中性文件名断言在原清单上实际失败，在新清单上通过。最终源码 ZIP 的 225 个成员、便携 ZIP 连同嵌套归档的 906 个成员均已完成已知标识与未批准文件类型复核，命中均为空；解包源码的 24 项定向回归为 22 通过、2 项文件符号链接权限跳过，再次归档的每个成员内容相同。此检查仍不保证识别未知敏感信息；扩展名白名单不能保证 Markdown 或图片中没有敏感内容。

本轮不改写 Git 历史、不强推，不宣称曾经公开过的旧素材名称已从历史或第三方缓存中撤回。

### 更新信任链

客户端保留 Ed25519 **公钥**是正确设计，私钥不应出现在代码或发行物。本轮保留可信 HTTPS 来源限制、清单签名、资产大小/SHA-256、安装前复核，同时新增 GET/重定向/最后写入前取消。相邻安全及取消回归实际执行通过。

复测命令（从仓库运行，用本机技能脚本位置替换占位路径）：

```text
python -I <exposure-audit-skill>/scripts/exposure_scan.py .audit/evolution-051/source/dist/VoxMasterAI --json --baseline .audit/evolution-051/exposure-baseline.json -o .audit/evolution-051/exposure-final.json
```

扫描和配套复核脚本只读自己的发行目录；标准库隔离模式避免加载待分析目录里的同名 Python 模块。

## 4. 客户端无法解决的问题

- 任何随客户端下发的长期私钥、服务 Token 或第三方凭据都可被取得，混淆/本地加密不能从根本解决。此类秘密应留在受控服务/发布环境；确需在线服务时采用服务端签发的短期最小权限凭据。
- 本项目目前没有服务端付费/订阅判定，不新增“客户端 isPro 即可信”的设计。将来若有计费/授权，最终判定应由服务端承担；不为此把当前本地 DSP、私人音频或算法无意义搬到云端。
- 客户端清单验签不能证明主观音质、消除系统信誉提示或替代发布环境审批。私钥保管、CI 写权限与人类听审批准属于发行治理问题。
- 静态扫描没有覆盖运行时内存、全部网络行为、实体设备、Windows 10 实机、低内存与长音频负载。未检查不等于安全。

## 5. 修复顺序

1. **P0／条件触发**：若确认真实凭据或私人媒体入包，停止公开发布、移出产物并轮换受影响凭据；本轮尚未确认上述 Qt/SciPy 告警属于真实秘密。
2. **P1**：最终包的源码选择和隐私内容审阅、隔离旧版升级/卸载、资产大小与 SHA-256，以及远程精确版本校验。保留签名/来源/听审门禁，不以扫描分数取代发行验收。
3. **P2**：在明确授权与证书条件具备后引入可信 Authenticode；逐来源处理自建原生库的路径映射/CFG；不篡改第三方库来制造“安全”。
4. **P3**：持续依赖审计和可重复构建；开源本地产品不以反逆向混淆或服务端化换取虚假的安全感。
