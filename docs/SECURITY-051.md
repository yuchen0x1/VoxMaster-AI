## 3. 逐项证据与修复

### 系统签名、调试与原生加固

`VoxMasterAI.exe`、`VoxMasterAI-CLI.exe` 和依赖属于正常可分析的本地客户端。当前安装器没有 Authenticode，可能触发系统信誉提示；不能宣传为系统签名发行物。真正修复需可信代码签名证书、时间戳和受控 CI 凭据，涉及证书/费用时先取得授权，不能生成自签证书冒充可信签名。

PDB 与构建路径要按 PE 来源定位：自行编译部分可在编译/链接时使用路径映射、可重复构建与适当符号管理；第三方 wheel/DLL 不应事后随意改字节、删除许可或破坏其已有签名。CFG 必须在编译工具链正确启用并实测，不能简单篡改文件头当作修复。

### “私钥”与“GitHub Token”的有限复核

以下文件有 PEM 标题字符串，但独立复核未匹配到由完整标题、Base64 多行正文及配对结束标记构成的标准 PEM 私钥块：

- `_internal/PySide6/Qt6Network.dll`：0 块。
- `_internal/PySide6/plugins/tls/qopensslbackend.dll`：0 块。
- `_internal/PySide6/plugins/tls/qschannelbackend.dll`：0 块。

这是对具体误报的有限证据，不覆盖 DER、加密容器、非标准 PEM、运行时秘密或全部字符串。未把任何命中的潜在秘密原文写入公开报告。

`_internal/scipy/optimize/_highspy/_core.cp311-win_amd64.pyd` 中 `ghs_` 命中偏移为 **5,545,739**，上下文确认是 `ghs_setCallbackP5HighsSt8function` 开头的 C++ 回调符号。扫描器把符号前缀当作 Token；无需删除 SciPy 或改写第三方二进制。

### 归档与客户端代码

`ThirdParty/Qt-notices.zip` 共 178 项，是许可/元数据及相关通知；`_internal/base_library.zip` 共 155 个 `.pyc`，是 Python 运行库。它们不是数据库转储。保留必需运行库和合法再分发材料，不为分数做破坏性“清理”。

便携包的 `_internal/certifi/cacert.pem` 是 HTTPS 使用的公共 CA 证书集合，不是私钥。复核确认其 SHA-256 与固定运行环境中的 certifi 文件完全相同，且可按 X.509 证书集合解析、没有 PRIVATE KEY 标记；只为这一精确路径和哈希放行，不放行任意 `.pem`。审计解析器对集合内既有非正序列号证书给出了未来兼容性警告，已保留；这不等于所有证书链或未来解析兼容性均已证明。

PyInstaller 包可以拆出字节码是预期；MIT 开源程序没有必要为阻止合法审阅加入强反调试、无益混淆或云端音频处理。源码包仍必须排除私人媒体、模型权重、缓存与凭据；扩展名白名单也不是文本敏感信息识别器，允许的文档仍需内容审阅。

- 静态扫描没有覆盖运行时内存、全部网络行为、实体设备、Windows 10 实机、低内存与长音频负载。未检查不等于安全。

1. **P0／条件触发**：若确认真实凭据或私人媒体入包，停止公开发布、移出产物并轮换受影响凭据；本轮尚未确认上述 Qt/SciPy 告警属于真实秘密。
2. **P1**：最终包的源码选择和隐私内容审阅、隔离旧版升级/卸载、资产大小与 SHA-256，以及远程精确版本校验。保留签名/来源/听审门禁，不以扫描分数取代发行验收。
3. **P2**：在明确授权与证书条件具备后引入可信 Authenticode；逐来源处理自建原生库的路径映射/CFG；不篡改第三方库来制造“安全”。
4. **P3**：持续依赖审计和可重复构建；开源本地产品不以反逆向混淆或服务端化换取虚假的安全感。
