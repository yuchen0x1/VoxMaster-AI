## 复现

在项目根目录设置 `VOX_MODEL_TEST_WEIGHTS` 为真实权重目录，两个固定模型文件应通过模型中心的离线校验。然后执行以下命令。pytest 采用无屏 Qt 平台，原生显示、高 DPI、硬件推理与插拔另外记录。

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m pytest -q
```

硬件与长稳检查独立于上述 105 项。DirectML、CUDA 均对两个模型实际运行并检查所用算子提供程序。Windows 10 无可用来宾，未计入通过项。完整压力日志包含第一次失败和修复后的结果。[兼容性](COMPATIBILITY-011.md) · [稳定性与性能](PERFORMANCE-011.md)
